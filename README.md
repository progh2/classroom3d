# 미림마이스터고 3학년 교실 겸 SW실습실 — 웹 3D 둘러보기

도면 A-101(책상 배치), A-601(좌석 좌표표) 기준으로 만든 1인칭 3D 교실입니다. (1 unit = 1 m, 원점 = 북서 내부 모서리)

## 실행
**가장 쉬운 방법: 압축을 푼 뒤 `classroom3d-offline.html` 을 더블클릭** — 서버·인터넷 없이 브라우저(Chrome/Edge/Firefox)에서 바로 열립니다.
(three.js·three-vrm·화면 이미지·애니 캐릭터 VRM을 모두 HTML 한 파일에 내장, 약 18 MB)

아래 폴더 버전(site/)은 수정·개발용입니다. `?cast=lowpoly`(100Avatars 출연진)는 폴더 버전에서만 됩니다.
```
cd classroom3d/site
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000  (같은 와이파이의 폰: http://<PC IP>:8000)
```
※ index.html 을 더블클릭(file://)하면 ES 모듈·VRM 로딩이 막혀서 안 됩니다. 아무 정적 서버로 열어 주세요. 인터넷 연결 불필요 (three.js·three-vrm 동봉).

## 조작
- PC: 클릭 → 마우스 시점 고정 / WASD·방향키 이동 / Shift 빠르게 / <kbd>C</kbd> 웅크리기·서기 / Esc 해제
- 폰·태블릿: 왼쪽 엄지 드래그 = 이동(조이스틱), 오른쪽 드래그 = 둘러보기
- 조명: 앞문 옆 '조명' 스위치를 조준해 클릭(폰은 탭) → 아침 → 점심 → 저녁 순환. 단축키 L, 폰은 오른쪽 위 💡 버튼도 가능.
- 문: 문을 조준하고 <kbd>E</kbd> 또는 클릭(폰은 탭) → 여닫이 문이 교실 안쪽으로 열림(앞문은 앞벽 쪽 경첩 → 앞벽에 붙음, 뒷문은 뒷벽 쪽 경첩 → 뒷벽에 붙음). 열린 문으로 복도(사물함·바깥 창)까지 걸어갈 수 있음.
- 스위치 판(앞문 옆 벽, 위에서부터 '조명' · '교탁 가운데' · '일반 수업'): 스위치를 조준하고 <kbd>E</kbd> 또는 클릭(폰은 탭). 켜진 스위치는 초록 LED.
  - 교탁 가운데: 단축키 <kbd>T</kbd>, 폰 🧑‍🏫. 교사 스탠딩 책상(모니터 2대 포함)과 선생님이 앞 가운데(X 3.3 m, 전자칠판과 TV 사이)로 옮겨가 학생을 바라봄. 다시 누르면 원래 자리(왼쪽 앞)로. 지나가는 길에 서 있으면 "비켜 주세요".
  - 일반 수업: 단축키 <kbd>G</kbd>, 폰 📖. 모든 학생 모니터가 폴을 축으로 왼쪽으로 돌아가(폴 기준 −92° + 팔꿈치 +132°) 책상 왼쪽 가장자리를 따라 서고, 도중에 VESA 스위블이 +40° 돌아 **화면은 안쪽(책상 가운데·학생 쪽, 동쪽에서 남쪽으로 약 10°)**, 미니PC가 붙은 뒷면은 바깥(창 쪽)을 향함. 움직이는 동안에도 창벽·기둥·앞 가림판·옆 책상에 닿지 않고 케이블은 관절 축 속에서 이어짐(모니터 남쪽 끝은 상판 끝보다 약 4 cm 나옴). 화면은 어둡게. 키보드·마우스는 와이어 바스켓 서랍 안으로, 책상마다 펼친 책(모니터를 피해 오른쪽으로, 위치·각도·표지색 조금씩 다름)과 책 앞쪽에 연필·펜(일부 자리), 3·11·13번 자리는 노트북 + 멀티탭에 꽂힌 충전기. 다시 누르면 실습실 배치로 정확히 복귀.
- 앉기: 빈 의자를 조준하고 <kbd>E</kbd> (폰은 🪑 버튼 또는 의자 탭) → 학생 눈높이(1.15 m)로 앉음. 일어서기는 <kbd>E</kbd>/<kbd>C</kbd>/<kbd>Esc</kbd> (폰은 🪑 또는 조이스틱). VRM 학생이 앉아 있으면 "자리 있음".
  - 아침: 푸르스름한 확산광, 직사광 없음 / 점심: 가장 밝음, 서쪽 창 햇빛 / 저녁: 밤하늘·도시 불빛, 천장등 빛 웅덩이, 화면 발광
- 출연진: 기본은 애니메 스타일(VRoid 공식 CC0 HairSample). 주소 뒤에 `?cast=lowpoly` → 100Avatars 로우폴리 출연진.

## 가정값 (도면에 없거나 '가정'으로 표시된 것)
- 바닥: 액세스플로어(슬래브 +200 mm) 마감면 = 높이 0. 출입문 확보구역(900×1,000, '바닥판 없음')은 슬래브 레벨 −0.2 m → 200 mm 단차 + 알루미늄 노싱·노란 논슬립 띠. 문·복도 바닥은 슬래브 레벨.
- 이동: 단차를 그대로 오르내림 (눈높이는 서 있는 바닥 + 1.6 m, 부드럽게 변함). 시작 위치는 앞문 안쪽(슬래브 레벨).
- 천장고 2.7 m (액세스플로어 마감면 기준, 가정)
- 천장(참고 사진 기준): 둘레 흰 평천장(폭 0.8~1.0 m) + 작은 원형 매입 다운라이트, 가운데 우물형 노출 천장(+0.38 m, 도장 슬래브·보·원형 덕트 2줄 — 기본은 밝은 크림색),
  우물 가장자리 간접조명(코브), 와이어로 매단 긴 LED 바 조명 6줄(동서 방향 = 앞벽과 평행, 한 줄 약 4.7 m), 우물 가운데(기둥 열 보 아래) 천장형 4방향 카세트 에어컨 1대 + 냉매 배관.
  기본은 사진처럼 밝은 크림색 노출 천장, `?ceiling=dark` → 어두운 노출 천장. 저녁 모드에서는 LED 바·코브·다운라이트가 빛남.
- 전자칠판·TV: 사용자 정정에 따라 학생 기준 왼쪽(서쪽) 전자칠판 X1,215~3,175, 오른쪽(동쪽) TV X3,430~5,350, 중심 높이 1.45 m, 돌출 100
- 앞문 Y100~1,000 / 뒷문 Y7,300~8,200 (W900, 슬래브 기준 높이 2.1 m, 교실 안쪽으로 여는 여닫이 유리문), 확보구역 900×1,000 빗금
- 서쪽 기둥 Y3,900~4,500, 돌출 240 / 서쪽 창: 정정(t1007)으로 창 아래 벽을 0.6 m 높여 창대 1.5 m ~ 창 위 2.4 m(천장 2.7 m 아래), 기둥 앞뒤 두 구간, 가로 안전 난간(창대 위 0.22 m), 커튼 아랫단 1.35 m
- 동쪽(복도) 벽 가운데 기둥: 서쪽과 같은 Y3,900~4,500·같은 마감. 12번 책상(X2 6,550)과 겹치지 않게 실내 돌출은 45 mm로 가정
- 학생 책상: 4열×5행(5행은 창가 2대), H740, 흰색 상판 + 회색 금속 프레임(옆면 개방) + 깊은 철망 바스켓 서랍(깊이 14 cm)
- 책상 앞 가림판(정정 t1009): 상판 앞(북쪽) 끝을 따라 책상 폭 전체, 상판 위로 9 cm, 상판과 같은 흰색 + 연회색 윗마구리
- 책상 앞(북쪽) 아래 짧은 가림판(H 0.40~0.665 m) + 학생 쪽을 보는 멀티탭(4구 + 스위치, 전원선은 바닥 콘센트 박스로). 1·4·7·10·13·16번은 휴대폰 충전기가 꽂혀 있음
- 책상 오른쪽(동쪽) 옆 가방 고리 + 책가방(색 10가지). 4열(4·8·12·16번)은 동쪽 벽과 5 cm라 가방 없음, 10·15번도 비움 → 18자리 중 12자리
- 뒤쪽 창가 구석: 공기청정기(0.34×0.32×0.8 m, PM2.5 표시창) + 아이패드 24대 충전보관함(0.8×0.46×1.03 m, 바퀴, 2단×12칸, 투명 아크릴 문, 20대 꽂힘·4칸 빔, 충전 LED). 17번 의자 뒤로 약 0.5 m 통로, 예비 자리(19)와 떨어짐. 둘 다 충돌 상자 있음
- 모니터: 아래 베젤이 상판 위 2.3 cm (정정 t1009 — 8 cm에서 낮춤, 키보드 뒤 끝 높이 2.2 cm 바로 위). 실제 암처럼 폴 칼라를 폴 따라 5.7 cm 내려 암·브래킷·VESA·미니PC·케이블이 함께 내려감. 검정 Dell 27"(615×365, 얇은 베젤, 뒷면 은색 DELL 로고·VESA 판). 미니PC(약 12.5×12.5×4 cm, 검은 유광 앞면 + 은색 알루미늄 테두리, 옆면 포트)는 모니터 뒷면에 납작하게, 뒤에서 볼 때 가운데 왼쪽(동쪽). 은색 VESA 판 + 은색 틸트 브래킷은 가운데 오른쪽(서쪽, 폴 쪽). 같은 높이, 일부 겹침. 책상·바닥에 본체 없음
- 키보드·마우스 케이블: 미니PC 옆면 USB 포트 2개 → 모니터 뒤 → 암 아래 → 폴을 따라 내려와 상판 위로 키보드·마우스 뒤까지. 일반 수업 모드에서는 상판 남쪽 끝으로 넘어가 늘어진 뒤 바스켓 앞 테두리를 넘어 서랍 속 키보드·마우스로 따라 들어감
- 케이블: 미니PC 옆면 포트에서 짧은 HDMI 루프 → 모니터 단자, 전원·LAN·모니터 전원은 VESA 스위블 축 → 암 아래 → 팔꿈치 → 폴 → 상판 왼쪽 옆 모서리(클램프 바로 남쪽) → 책상 옆으로 내려가 아래 짧은 묶음(벨크로 타이) → 책상 밑 액세스플로어 바닥 콘센트 박스(브러시 그로밋)
- 모니터암: 검정 폴(약 45 cm) + 칼라(상판 위 약 16 cm) + 긴 첫 마디(약 28 cm, 팔꿈치는 VESA 브래킷 바로 뒤) + 짧은 둘째 마디 + VESA 스위블·틸트 브래킷. 책상 왼쪽 앞(북서) 모서리에 C-클램프로 고정 — 앞 가림판 때문에 클램프는 왼쪽(서쪽) 옆 모서리를 물음(윗 턱은 가림판 바로 뒤)
- 의자: 주황 타공 플라스틱 + 회색 다리, 450×450
- 벽 마감(사진 참고): 앞·뒤·창 아래 연한 원목 패널 + 몰딩, 위는 흰 벽 / 앞벽 시계·태극기 액자, 남는 앞벽은 유리 화이트보드 / 서쪽 창 흰 창틀 + 회색 커튼
- 동쪽(복도) 벽: 바닥~1.4 m 아이보리 평판 패널(세로 줄눈), 1.4~2.4 m 고정 유리 2장(가운데 기둥 양쪽, 열리지 않음, 얇은 은색 알루미늄 틀), 위는 흰 벽, 앞문·뒷문은 슬래브 레벨의 알루미늄 틀 유리문. 복도 폭 2.5 m 가정, 저녁엔 어둡게
- 복도 맞은편(동쪽 끝) 외벽: 바깥 창 6칸(창대 1.0~2.3 m)
- 복도 사물함(정정 2026-10-09): 교실 쪽 복도 벽(교실 동쪽 벽 바깥, 아이보리 패널·유리 아래)에 붙여 복도를 향함. 2단, 깊이 0.45 m, 한 칸 폭 0.4 m, 윗면은 복도 바닥에서 1.05 m(유리 창대 1.6 m보다 낮아 유리를 가리지 않음). 앞문·뒷문 앞(0.35 m 이상)과 가운데 기둥 앞은 비움 → 2+6+6+2칸(×2단 = 32개)
- 교사 스탠딩 책상 H1,000, 27" 모니터 2대(교사 쪽 = 북쪽을 향함), 교사 서는 위치 Y≈420
- 천장 조명: 도면의 평판등 대신 사진 기준 LED 바 6줄(동서 방향) + 둘레 다운라이트, 에어컨 1대 (위 천장 항목)
